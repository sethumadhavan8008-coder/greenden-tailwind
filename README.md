# 🌿 Greenden - Plant Store Website

Greenden is a modern, responsive plant store website built using **HTML** and **Tailwind CSS**. The website provides a clean and user-friendly interface for browsing indoor plants, exploring products, and contacting the business.

---

## 📌 Features

- 🌱 Fully Responsive Design
- 🏠 Attractive Home Page
- 🛍️ Product Listing Page
- 🔍 Product Search Bar
- 📞 Contact Page with Contact Form
- 📱 Mobile-Friendly Navigation
- ⭐ Customer Reviews Section
- 📧 Newsletter Subscription Section
- 🎨 Modern UI using Tailwind CSS
- ⚡ Fast and Lightweight

---

## 🛠️ Built With

- HTML5
- Tailwind CSS
- Responsive Web Design
- SVG Icons
